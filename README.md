## 下单页不会提醒的几件事

**共享资源，没有 SLA。** 这个价位卖的是共享 CPU 和大带宽，不是保障型实例。核心生产业务放上去，出问题要有自己扛的准备。

**公司成立时间短。** 2023 年注册，到现在三年多。预付一年之前，先想清楚这笔钱的风险承受度。

**日本和洛杉矶的 Pro 系列定位不明。** JPPro、LAXPro 比同地区的 Lite/Hyper 系列贵，带宽和流量反而少。官方没写明网络差异，只看带宽和流量的话这两个系列不划算。真要买，先在下单页找到线路说明。

**硬盘是硬约束。** 5GB 和 10GB 的档位一大把，系统加面板就占掉一半。选档时把硬盘当第一筛选项，比看 CPU 核数有用。

同类产品的坑可以提前知道：

- 甲骨文云 Always Free 的 Ampere A1 现在折合 2 核 12GB，旧教程里的 4 核 24GB 是旧额度；闲置 7 天三项指标都低于 20% 可能被收回。
- cPanel & WHM 官方不支持 ARM，要装这个面板就别选 ARM 机型。
- Hostinger 的"云主机"是托管型，拿不到 root 权限，和 VPS 不是同一种产品。

这些是别家的规则。AkileCloud 的退款期限、是否支持 Windows、续费是否同价，官网没有公开说明，下单前问一次客服。
